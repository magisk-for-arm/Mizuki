# 为什么接触模拟器

我用过的模拟器不算很多，不过市面上主流的也就那些。下面分享一些使用心得。
我是从植物大战僵尸开始接触模拟器的,现在在用模拟器玩那些没有移植版本的galgame


# 我的评价

## ExaGear

一款老牌 Windows 模拟器，也是我接触的第一款模拟器。

**优点**：配置要求低、易用性强，对《红警2》《龙族》等上古游戏兼容性极佳。

**缺点**：因为是 32 位应用，几乎无法运行现代游戏；开发者已停更，新游戏兼容性每况愈下；DX10/11 支持较差。

所以说，我现在已经基本不再使用 ExaGear。

## Winlator

我目前主力使用的模拟器。基于 Wine + Box64 + DXVK，能运行相对现代的游戏，效率比 ExaGear 更高，还支持容器化管理。

**不足之处**：对于部分游戏存在兼容性问题，偶尔会出现卡屏；同时第三方改版众多对于不同设备的兼容性也不同(我目前用的是af大佬的)

## Mobox

另一款基于 Wine + Box64/Box86 的模拟器，需要 Termux 环境运行。
> [!NOTE]
> 目前已经停更

与 Winlator 相比，Mobox 配置更为灵活，上手门槛比winlator高，而且要一定的 Linux 命令行基础。但在我的设备上会没有声音(~~玄学~~)

> [!TIP]
> 用模拟器玩游戏最好用高通的SOC,其他家的没有开源驱动支持,性能不如高通
